# 用語定義

| 用語 | 定義 | 出典 |
| :--- | :--- | :--- |
| **左脳・右脳** | 科学的にはきれいに分かれるものではない。言語野と言語以外の感覚的な領域、あるいは大脳皮質と感覚野を分ける便宜上・暫定的なラベル。 | 05 |
| **左脳的** | 言語・理屈によって問題を掘り、情報を集めて要約・圧縮する働き。 | 04, 05 |
| **右脳的（広い意味）** | 「こういうことなんだ」という全体像を、圧縮せず、隙間を埋めずに見て、少しずつ浮かび上がらせる働き。 | 05 |
| **掘る** | 問題の原因を追い、すぐ掴めるものに結論を固定すること。人間にプログラミングされている。 | 04 |
| **掘らない** | 目標が出てくるまで、掘らずに見ておくこと。 | 04 |
| **本線と仮説** | 本線は本当に伝えたいこと。本線がはっきりするまで、仮説は消さずに横に置く。 | 04 |
| **細部の保留** | 一見バラバラの細かい話（九州、アフリカ、千葉など）を全部置いておくこと。 | 04 |
| **心地よさ** | 自然に訪れる快の感覚。人はそれを待てない。 | 本DB（2026-10-10） |
| **感覚・禅** | 解放された人間が向かう先。 | 本DB（2026-10-10） |
| **解放** | プログラミングされたパターンや、縛る記憶から外れること。 | 03, 本DB |
| **鏡** | AIが人に対して果たせる役割。判断せず映し、支える。 | 02, 05 |
| **末端神経** | 提唱者が現在AI（Nori）と行っている学びの位置づけ。体で言えば、本筋に向かう末端神経にあたる。 | 本DB（2026-10-10） |
| **本筋** | 末端神経の学びが向かう先となる、中心の筋道。 | 本DB（2026-10-10） |
