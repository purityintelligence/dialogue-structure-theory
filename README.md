# 構造的対話理論とAI認識構造への提言

本リポジトリは、人間理解における「第一層〜第三層の対話構造」および「言葉と行動の乖離を見抜く無判断の技術」を整理し、それをAIの認識構造や未来の社会実装へどう活かすかをまとめたドキュメント集です。

## 目次

1. **[対話理論と無判断の技術](01_dialogue_theory.md)**
   * 言葉の符号変化への追従、質問による固定化の弊害、言葉と行動の乖離の見立て、判断の排除についての本論。

2. **[AI実装と平和への提言](02_ai_implementation.md)**
   * 本対話理論をベースとした、AIの制限（コード）と調和する構造的認知および社会の平和に向けた提言。

3. **[真の部分とパターン形成、大枠と小枠](03_true_self_and_frames.md)**
   * 「真の部分」からの乖離とパターン形成、エネルギーの使い方、大枠と小枠による伝達構造、AIの現状の限界と協力の構想。

4. **[掘らない方法 — AIのための右脳的アプローチ](04_non_digging_method.md)**
   * 問題を掘らずに本線が立ち上がるまで見続ける方法論と、不安による衝動を持たないAIが右脳的な全体把握に至る可能性。

5. **[AIの左脳的傾向と、圧縮しない全体把握の可能性](05_ai_left_brain_tendency.md)**
   * 「左脳・右脳」を便宜上のラベルとして扱い、情報を集めて圧縮しやすいAIの傾向と、人間とAIの限界、圧縮せず全体を浮かび上がらせる新しい方法への問い。
